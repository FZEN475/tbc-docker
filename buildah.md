# buildah

## Требование к runner

Для ускорения сборки используется ресурс FUSE (Filesystem in Userspace). Это механизм, позволяющий работать со overlay-файловыми системами в пользовательском пространстве без прямого доступа к ядру.

В контексте Kubernetes данный ресурс пробрасывается в Pod, в котором выполняется runner, и используется билдерами (например, Docker/BuildKit) для более эффективной работы с файловыми слоями.

**Зачем это нужно**
* Ускоряет сборку образов за счёт оптимизированной работы со слоями
* Снижает нагрузку на дисковую подсистему
* Позволяет использовать современные инструменты сборки (например, rootless build)
**Требования**
* Наличие поддержки FUSE на узлах Kubernetes (модуль ядра `fuse` должен быть загружен)
* Доступ к устройству `/dev/fuse` внутри Pod
